Privacy, with perspective

Built to protect.
Honest about limits.

Read the privacy & security details →

Imported files use authenticated AES-256-GCM encryption. Password-derived protection and Android Keystore guard the vault keys. Viewing decrypts the data needed for the current view, not the entire library into a public folder.

Safe Mode locks when you leave. Temporary Normal Mode deliberately keeps the vault unlocked in the background until screen-off restores Safe Mode.

No app can promise protection from a fully compromised operating system, guaranteed physical erasure, or the recall of files someone has already copied. Keep a verified backup and a strong password.

How do I install and open the app?
  1. Download the APK from this page on a compatible Android device.
  2. If Android asks, allow this browser or file manager to install this app. Review the system prompts. You can revoke the install permission afterward; do not disable Play Protect.
  3. Open Clock. On the initial minimal screen, draw a deliberate X in two strokes to open setup. Create and confirm an alphanumeric password of at least eight characters.
  4. Import a small test file first and make sure you can reopen it. Keep originals until you have verified your import and backup.

Android or your device administrator may restrict installation. Follow official platform guidance; a website cannot override those restrictions.

Is this a Play Store app?

This page distributes an independently signed APK, not a Google Play listing. Updates require downloading and installing a newer release over the current app.

Android developer-verification rules are evolving. Google's current guidance distinguishes the initial participating-store rollout from direct sideloading and describes an advanced flow for unregistered apps. Check the official Android guidance for your device and region. Hosting a download is not Google approval.

Does everything need the internet?

No. The encrypted library and clock work locally. Private chats use third-party encrypted relays while unlocked. Explicit public-link imports also use the internet. Offline Nearby sharing needs a compatible shared local network, but no chat identity or internet connection.

What happens if I forget my password?

There is no password-reset service that can recover your vault. Uninstalling, clearing app data, or losing the installation's Keystore key can make local data unrecoverable.

A separately created library backup can restore the backed-up library with its own backup password. It does not recover the original password or chat identity/history. Test your backup before relying on it.

What should I know about group sharing?

Use version 3.20 or later on every recipient's device for vault-file sharing. Group files use relay delivery, not Nearby, and have a 100 MiB per-file limit. Receipt tracking waits for the original recipients' confirmed vault saves before automatic relay cleanup.

Members can retain or export copies. Removing a member does not erase those copies, and groups are not anonymous to their members. Missing receipts, offline users, and relay expiry can affect availability. Removing a member and cancelling a transfer can show a connection warning; Retry reconciles the remaining chats.

Can I read the source or report an issue privately?

The matching source, build instructions, and third-party source materials accompany each public APK release under AGPL-3.0. See licensing and source availability.

What changed in version 3.20?

Encrypted group conversations, invitations, member verification, admin controls, and vault-file sharing were added. Recipient-aware save receipts prevent the first recipient from causing early cleanup for everyone else. The existing vault theme and locking behavior are retained.

This release was exercised on emulators; compatibility across every manufacturer and device is not guaranteed.
